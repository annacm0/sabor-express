# 🍽️ Sabor Express

Aplicação desenvolvida em **Python** para gerenciamento de restaurantes, criada com foco na prática de conceitos de programação e na evolução da estrutura do código.

O projeto foi desenvolvido em etapas, começando com uma implementação utilizando fundamentos da linguagem Python e posteriormente evoluído para uma versão utilizando **Programação Orientada a Objetos (POO)**.

## 🚀 Sobre o projeto

O Sabor Express permite trabalhar com informações de restaurantes, incluindo:

* Cadastro de restaurantes;
* Listagem de restaurantes;
* Controle do status de atividade;
* Categorias de restaurantes;
* Avaliações;
* Organização dos dados por meio de classes e objetos na versão orientada a objetos.

A evolução do projeto permitiu aplicar diferentes conceitos de desenvolvimento e comparar uma implementação inicial com uma estrutura mais organizada utilizando POO.

## 🛠️ Tecnologias

* **Python 3**
* Programação Orientada a Objetos

### Versão inicial

O arquivo `app.py` contém a primeira implementação do projeto, desenvolvida utilizando os fundamentos de Python.

### Versão Orientada a Objetos

A pasta `orientacao-objetos/` contém a evolução da aplicação, utilizando classes para representar e organizar os elementos do sistema.

O modelo `Restaurante` concentra comportamentos e informações relacionados aos restaurantes, enquanto `Avaliacao` representa as avaliações associadas.

## ▶️ Como executar

### Versão inicial

Na raiz do projeto:

```bash
python app.py
```

### Versão Orientada a Objetos

Acesse a pasta:

```bash
cd orientacao-objetos
```

Execute:

```bash
python app.py
```
